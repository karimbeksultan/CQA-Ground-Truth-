## 6. Как проверить харнесс самостоятельно

```bash
.venv/Scripts/python.exe -m pytest -q
```

```bash
.venv/Scripts/python.exe -m cqa checklists
```

```bash
.venv/Scripts/python.exe -m cqa run --group DEV --evaluator optimistic
```

Чтобы увидеть отчёт с цифрами, заполните `answers` у пары диалогов в `eval/goldens/DEV.jsonl`
(значения `"yes"`, `"no"`, `"na"` или число шкалы) и повторите `run`: в `runs/<id>/report.md`
появятся метрики по каждому критерию. Проверить подсчёт балла вручную: правило S4 выше
(пример 77.69).
