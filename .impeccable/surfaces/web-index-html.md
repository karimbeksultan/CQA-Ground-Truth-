# Surface brief: CQA workspace (web/index.html)

Mode: Operate. Audience: quality analyst and reviewer at Freedom Broker; demo on a laptop + projector.
Job: load dialogs, run checklist evaluation, read verdicts with evidence, appeal, decide, edit checklists.
Constraints: plain HTML/CSS/JS, no build, embeddable as a Dynamics 365 web resource; UI in RU/EN/KZ.

## Direction contract
THESIS: a QA workbench where every point is traceable to a turn; refuses the dashboard-of-cards default.
OWN-WORLD: Freedom near-black green ground, logo green #06AE3C for primary action, neon mint for evidence and focus; Doom forest-green cloak for the shell rail and selection, gunmetal steel for structure and secondary text; system UI sans with tabular numerals.
STORY: the visitor sees which dialogs scored what, opens one, follows each verdict to the exact turn or second of the call, disputes it, and watches the reviewer's decision move the total.
FIRST VIEWPORT: left steel-edged cloak rail (nav, role, language); dialog table as the work area with import/upload toolbar and live job progress strip above it; selection drives "Оценить".
FORM: pinned by the user's palette brief (no concept roll); signature move = weight ribbon showing effective weights, N/A collapse and before→after on decisions. seed: none (unavailable)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
